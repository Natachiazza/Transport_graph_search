# Transport Graph Search

Поиск маршрутов между городами по расписанию с недельной периодичностью.
Проект по алгоритмам на графах на **C++17** с использованием **только STL**
(без сторонних библиотек).

---

## 🎯 Задача

Дана транспортная сеть: города, виды транспорта и рейсы с расписанием
(дни недели, время отправления, длительность, стоимость). Нужно находить
оптимальные маршруты между городами с учётом расписания и фильтра по видам
транспорта.

Проект покрывает пять режимов поиска:

| # | Режим | Алгоритм | Сложность |
|---|-------|----------|-----------|
| 1 | Кратчайший по времени путь | Дейкстра (по времени, tie-break по стоимости) | `O(V² + E·7)` |
| 2 | Самый дешёвый путь | Дейкстра (по стоимости, tie-break по времени) | `O(V² + E)` |
| 3 | Минимум пересадок | BFS | `O(V + E)` |
| 4 | Города в пределах бюджета | Дейкстра с отсечением по бюджету | `O(V² + E)` |
| 5 | Города в пределах времени | Дейкстра с отсечением по времени | `O(V² + E)` |

Для всех режимов — фильтр «только эти виды транспорта» / «все, кроме».

---

## 🧩 Архитектура

- `Time` — время с недельным периодом (день + часы + минуты)
- `Edge` — рейс: `from`, `to`, `transport`, `days`, `startTime`, `duration`, `price`
- `Path` — последовательность рёбер с накопленными характеристиками
- `Graph` — загрузка из файла, индексы по городам/транспорту/рейсам
- Алгоритмы поиска — свободные функции, принимающие `const Graph&`
- `UI` — интерактивное консольное меню

**Ключевая идея:** «время при отправлении» зависит от текущего дня недели —
поэтому `nextDeparture(cur)` ищет ближайший рейс за период до 7 дней вперёд
за `O(7)`, а не разворачивая граф по дням.

---

## 📄 Формат входного файла

```
"from_city" "to_city" "transport_type": { "cruise_name" days HH:MM duration fare }
```

- `days` — битовая маска из 7 символов (Пн…Вс), например `1011101`
- `duration` — в минутах, `fare` — условные единицы

Пример: [`data/graph.txt`](data/graph.txt)

---

## 🚀 Сборка и запуск

```bash
# сборка
g++ -std=c++17 -O2 -Wall -Wextra src/main.cpp -o transport

# запуск (файл с графом — первым аргументом)
./transport data/graph.txt
```
Если аргумент не указан — программа запросит имя файла

## 🛠️ Что в проекте

- Модификация классических алгоритмов (Дейкстра, BFS) под задачу с
  зависящими от времени весами (расписание)
- Работа с битовыми масками для дней недели
- Разделение доменных классов и алгоритмов
- Разбор неструктурированного текстового формата
- Обработка ошибок ввода (неизвестный город, некорректная строка расписания)
- C++, STL, без сторонних зависимостей
